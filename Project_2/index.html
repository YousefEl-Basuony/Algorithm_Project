Divide & Conquer Complexity Breakdown

Both Merge Sort and Quick Sort decompose problem sets into smaller subproblems. However, their partition behavior and memory access patterns lead to sharply contrasting trade-offs:

Algorithm Best Average Worst Case Space
Merge Sort O(n log n) O(n log n) O(n log n) O(n)
Quick Sort (Last Pivot) O(n log n) O(n log n) O(n²) O(log n)

The O(n²) Last-Element Pivot Trap

When selecting the arr[high] (last element) pivot on Reverse Sorted or Already Sorted arrays, the partition divides the array into subsets of size 0 and n - 1 instead of two equal halves.

Try it in the Visualizer: Select Quick Sort (Last-Element Pivot) with Reverse Sorted data. Watch the comparisons count skyrocket to near \( \frac{n(n-1)}{2} \) operations! Then switch to Random Pivot to see the issue resolved.
